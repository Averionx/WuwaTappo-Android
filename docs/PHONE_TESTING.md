# 手机测试与权限说明

应用：Wuwa Tappo Android版；基础：Xime；最低 Android 9；当前 APK：arm64-v8a。

## 设置首页

![设置首页的三个入口](images/tutorial/01-start.png)

真机截图：Android 16 / vivo。① 进入系统启用本输入法；② 将它选为当前输入法；③ 进入桌宠设置。首次安装请先完成应用内的方案选择与部署。

## 安装与启用

1. 安装 APK。与 Xime 官方版及原 Fcitx5 桌宠试验版可以并存，需要重新在系统中启用本输入法。
2. 打开应用完成引导，等待输入方案部署完成，再切换为“Wuwa Tappo Android版”。首次部署词库可能需要等待。
3. 默认选择拼音九键、中文输入。键盘菜单→输入方案可换成普通拼音全键盘、五笔或其他方案；中英文切换键仍保留。
4. 键盘菜单→Wuwa 桌宠（或应用设置→外观→Wuwa 桌宠），等待内置图鉴准备完成。无需导入素材。
5. 点击“管理悬浮窗权限”，在系统中允许本应用“显示在其他应用上层”，返回后开启桌宠。

## 权限

- **显示在其他应用上层／悬浮窗**：用于将桌宠放在键盘外；拒绝时键盘仍应可以使用。部分厂商另有“后台弹出界面”等限制，可按系统提示允许。
- **麦克风**：仅在使用语音输入时需要，不是桌宠权限。
- **网络**：保留 Xime 的商店、插件、在线语音、同步和更新能力。桌宠资源和动作在本地运行，不加入 Wuwa 联机或房间。
- 桌宠没有常驻通知或单独的后台桌宠服务；它跟随输入法窗口生命周期显示。无需为桌宠申请通知、无障碍或录屏权限。

系统提示输入法可能读取输入内容属于输入法通用提示。桌宠的动作接口只接收敲击通知，不读取按键字符。Xime 及用户安装插件的网络行为仍按各自实现和配置运行。

## 建议测试

- 输入“你好”“今天的天气很好”及中英文混输，检查九键候选、选词上屏、删除、长按和切换方案。
- 连续打字时左右动作切换，停止输入约 220 ms 后恢复待机；角色仍定时眨眼。
- 更换角色外观和头饰，选择表情；打字偶尔弹出 1–2 个表情，连续戳戳可连续触发。
- 关闭桌宠后继续打字，再开启，检查输入正常且桌宠能够恢复。
- 收起键盘、切换应用、进入密码框、旋转屏幕，检查悬浮窗不会残留或遮挡键盘。
- 开启触摸穿透后，原桌宠位置可以点到下方应用；此时不能戳戳。关闭穿透后恢复戳戳。
- 测试原有手写、语音、插件、主题、商店和同步入口。网络服务是否可用取决于相应服务、模型和用户配置。

## 常见情况

- **看不到桌宠**：检查系统悬浮窗许可和桌宠开关；打开普通文本框并显示键盘。密码框会隐藏桌宠。
- **不能戳戳**：检查是否开启触摸穿透；开启拖动模式时，轻触仍可戳戳，明显拖动只移动位置。
- **桌宠挡住聊天**：拖到其他位置、缩小，或使用触摸穿透；也可关闭桌宠继续使用输入法。
- **仍是旧输入法或英文**：确认当前输入法确为本 Xime 桌宠版本；用户会话内手动切英文仍有效，数字和密码输入框保留相应专用行为。
- **更新提示下载 Xime 官方版**：官方包不包含本项目桌宠功能，是独立应用；本衍生版需使用自己的新版 APK 更新。
