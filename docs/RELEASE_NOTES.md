# WuwaTappo Android版 1.0

- 本版作者、维护与发行署名为 Averionx；关于页、设置、启用向导、候选栏和无线导入页面统一使用 Wuwa Tappo 标识，保留独立的上游开源致谢。
- 应用图标使用 Wuwa Tappo 桌面版原始 Logo；项目主页补充完整的安装、悬浮窗授权和桌宠使用说明。
- 改用 Xime 为基础，保留原有输入法功能和网络能力。
- 桌宠版编号 1.0，宿主兼容版本保留 Xime 3.4.1，避免商店和插件版本约束失效。
- 默认九键拼音、中文输入，保留全键盘、五笔及中英文切换。
- 加入独立悬浮桌宠，提供打字动作、待机眨眼、戳戳和偶发表情。
- 键盘菜单和应用设置均可进入桌宠设置，切换角色外观、头饰和表情。
- 内置 260 套外观、135 个头饰、504 个表情，无需手动导入；不包含 Wuwa 房间和联机。
- 可开启、关闭、拖动、调整大小和触摸穿透；密码框和键盘收起时隐藏。

需要 Android 9 或更新系统、arm64-v8a 设备。独立包名 `com.wuwatappo.android`，安装后需在系统中启用。桌宠需“显示在其他应用上层”许可。当前为 Debug 签名测试构建。

263 项定向自动化测试通过，APK 签名、资源完整性与原生库 16 KB ELF 对齐检查通过；已完成 Android 16 真机覆盖安装与设置首页检查，完整输入与悬浮窗流程尚未完成实测。远端服务与全部插件未逐一验证。

源代码遵循 GPLv3，移植模块保留 LGPL 许可说明。角色、头饰和表情素材归原权利人所有，未随代码许可证重新授权。1.0 APK、对应源码和校验文件通过 GitHub Release 提供。

## 关于页显示修复

修复应用标题在换行时行距过小、两行文字相互重叠的问题。标题居中并设置独立行高；顶部导航标题过长时省略显示。新增窄容器、1.5 倍字体的原生排版回归检查，263 项定向测试全部通过。

## 下载与安装

普通用户下载 `Wuwa-Tappo-Android-1.0-arm64-v8a.apk`。安装后启用并选择本输入法，在 Wuwa 桌宠设置中授予悬浮窗权限并开启桌宠。已内置素材，无需手动导入。

当前包名 `com.wuwatappo.android`，versionCode `20261028`；继续使用与手机测试版相同的 Debug 证书，覆盖安装保留本地设置和词库。应用内项目与发布链接现已指向本项目仓库。
